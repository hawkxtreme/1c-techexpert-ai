# Готовность сервера: процесс запущен, приложение может быть недоступно

Разделяйте проверки: бинарные файлы установлены; процессы запущены; RAS отвечает; СУБД доступна; тестовая ИБ создана; клиентское приложение действительно работает. Успех предыдущего шага не заменяет следующий.

В лаборатории PostgreSQL и административные операции 1С работают, но существующая лицензия привязана к другой среде. Перенос файла не создаёт действующую лицензию. Не редактируйте файл лицензии и не имитируйте аппаратную привязку. Дальнейшие действия с лицензированием на этом ПК пользователь исключил; серверный сценарий отмечен как непроверенный.

Windows-клиент и сервер внутри Docker также могут иметь проблему определения принадлежности процессов одному компьютеру при NAT. Это отдельная причина, отличная от отказа лицензии. Аналогичная граница обсуждена в [репозитории 1С](https://github.com/1C-Company/docker_fresh/issues/7). Нельзя исправлять её глобальными изменениями сети без отдельной подготовки.

Для продуктовой готовности проверяйте фактическое действие минимальным контролируемым случаем. Профиль среды, версия и ограничения входят в результат. Руководство по серверной установке: [1С](https://1c-dn.com/library/tutorials/1c_enterprise_administrator_guide_client_server_mode_8_3_27/).
