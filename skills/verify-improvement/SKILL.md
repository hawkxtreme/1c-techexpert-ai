# Проверка исправления

Используйте [investigate](../investigate/SKILL.md) и фактические case_id. Для поддержанного sc01-order-load-v1 выполните `compare --before ID… --after ID…`, затем продолжайте через comparison ID. Пять независимых пар — условие текущего протокола; дубликаты одного запуска не считаются повторами.

Отдельно оцените применение изменения, сравнимость условий, правильность результата, изменение времени, достижение цели и последующее наблюдение. Быстро записанные неполные данные не являются улучшением. Медиана не позволяет выбросить неудобный запуск; учитывайте порядок, прогрев, начальное состояние и точность часов.

Для других шаблонов этот конкретный compare не является универсальной статистической проверкой. Подготовьте и исполните разрешённый сопоставимый опыт средствами harness, сохранив источники и ограничения. Не объявляйте «исправлено навсегда» по одной быстрой попытке.

Команды запускайте из проверенного корня пакета; [общий контракт](../techexpert/references/local-cli.md) задаёт состояние и формат ошибок.
