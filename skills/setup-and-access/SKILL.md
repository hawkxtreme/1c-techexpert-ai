# Настройка и доступы

Из проверенного корня пакета выполните `python techexpert.py doctor`, затем `init`. Пользователь остаётся в своём ИИ-harness; GUI настраивает источники и не создаёт отдельного агента. После сохранения прочитайте `profile` с тем же --state-dir и продолжите исходную задачу.

Импорт стартера читает только выбранный .v8i. Проверка RAS выполняется отдельной кнопкой и читает списки. Адрес SQL из summary не выводится. Для файловой базы SQL/RAS неприменимы; общие ресурсы серверных ИБ связываются с несколькими базами. Данные остаются по разным адресам.

Локальная готовность проверяет каталоги и наличие клиента, не подключает СУБД и не запускает сбор. Различайте «настроен», «инструмент доступен», «подключение проверено» и «данные нужного периода получены». Для отсутствующих прав подготовьте адресное задание администратору; не включайте WinRM/SSH и не меняйте logcfg из сохранения профиля.

Команды запускайте из проверенного корня пакета; [общий контракт](../techexpert/references/local-cli.md) задаёт состояние и формат ошибок.
