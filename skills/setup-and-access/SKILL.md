# Настройка и доступы

Из проверенного корня пакета выполните `python techexpert.py doctor`, затем `init`. Пользователь остаётся в своём ИИ-harness; GUI настраивает источники и не создаёт отдельного агента. После сохранения прочитайте `profile --resolved` с тем же --state-dir и продолжите исходную задачу. Это временное представление настроек адаптеров; исходный профиль с общими ресурсами доступен через `profile`.

Профиль 2 хранит общие узлы, кластеры, экземпляры СУБД и подключения по идентификаторам. В GUI адрес и ссылка на доступ редактируются один раз; имена SQL-баз задаются отдельно. Учитывайте показанный перед сохранением список затронутых баз и источников. После смены подключения прежнее соответствие экземпляра и область прав требуют новой проверки; пользовательские идентификаторы остаются сообщёнными сведениями. Не заменяйте граф плоским представлением из --resolved. Старые профили читаются без перезаписи; `profile-upgrade FILE` преобразует выбранный документ, `profile-impact BEFORE AFTER` показывает конфигурационные зависимости. Эти команды не сохраняют профиль и не подключают источники. Не просите пользователя составлять JSON или вручную описывать всю инфраструктуру.

Импорт стартера читает только выбранный .v8i. Проверка RAS выполняется отдельной кнопкой и читает списки. Адрес SQL из summary не выводится. Для файловой базы SQL/RAS неприменимы; общие ресурсы серверных ИБ связываются с несколькими базами. Данные остаются по разным адресам.

Локальная готовность проверяет поля и связи без обращения к заданным каталогам и executable. Различайте «настроен», «инструмент доступен», «подключение проверено» и «данные нужного периода получены». Для отсутствующих прав подготовьте адресное задание администратору; не включайте WinRM/SSH и не меняйте logcfg из сохранения профиля.

У каждого источника в GUI есть серые пояснения ожидаемого формата и примера, назначение, права и раскрываемая подготовка Windows/Linux. Тот же текст доступен через `source-help tj|jr|source|sql|rac|os`; справка поставляется в пакете и не требует внешнего поиска. Когда ID расследования уже известен, откройте `init --investigation ID`: описание отображается из чата. Пользователь настраивает источники и сохраняет профиль расследования.

Шаблон, период и охват эпизода агент уточняет в текущем чате. Команды запускайте из проверенного корня пакета. [Общий контракт CLI](../techexpert/references/local-cli.md)

Для журнала на удалённом узле используй [план SFTP и получение выбранных файлов](../techexpert/references/remote-journals.md): транспорт отдельно от формата, сохранение/GET не соединяются, анализ сохранённого capture не переподключается.

## Локальное обновление

1. Используй тот же `--state-dir` и вызови `update-check PACKAGE.zip` для выбранного пакета. При необходимости укажи текущий корень `--current-root PATH`. Покажи версии, изменения программы и знаний, пересечения с локальными правками и активность. Сверь хэш пакета с доверенным источником. Пользователь выбирает «Обновить», «Позже» или «Подробнее».
2. После подтверждения сохрани объект `plan` из ответа и передай его в `update-stage PLAN.json --expected-sha256 HASH`. Хэш бери из `plan_sha256`. Каждый пакет сохраняется в своём каталоге. Исходный checkout и частные расследования остаются доступны.
3. Для управляемого локального профиля Codex 0.164.0 дождись завершения сбора и записи. Установку запускай в согласованное окно, когда этот профиль готов к переключению. Получи план через `update-plan RELEASE_ID --codex-profile PATH --maintenance-window` и передай его в `update-apply PLAN.json --expected-sha256 HASH`. Команда читает обратно установленный комплект. `update-status` показывает выбор площадки. Загрузку новой версии в работающем клиенте проверяй отдельно. Для профиля с обычной площадкой `1c-techexpert-local` доступна подготовка пакета и отдельный управляемый профиль.
4. После прерывания повторно прочитай результат по тому же плану. Для возврата выбери ранее подготовленный `RELEASE_ID` и получи план для него. При локальных правках сохрани пользовательские файлы до замены. При несовместимости открывай сохранённые материалы прежним комплектом. Обновление знаний сохраняет закреплённые материалы и требует проверки их применимости при повторном использовании.
