# Кластер 1С

Для файловой ИБ этот маршрут не нужен. Для серверной начните с [rac](../rac/SKILL.md), затем свяжите ИБ, кластер, рабочие серверы, процессы, соединения и сеансы в пределах одного наблюдаемого периода.

Времена получения разных списков могут различаться. Один PID или session-number без начала жизни и принадлежности не устанавливает связь со старым ТЖ. Не считайте список кластера доказательством успешного запуска приложения: лицензия и реальный клиент проверяются отдельно.

Проверяйте метрики узлов и доступ к СУБД отдельно от RAS. Используйте команды чтения, соответствующие выбранной базе. [Метрики ОС](../os-metrics/SKILL.md) · [SQL Server](../sql-server/SKILL.md) · [PostgreSQL](../postgresql/SKILL.md)

Команды запускайте из проверенного корня пакета; [общий контракт](../techexpert/references/local-cli.md) задаёт состояние и формат ошибок.
