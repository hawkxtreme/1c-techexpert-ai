# Помощник настройки ТЖ

Навык включён в комплект, но отдельного исполняемого адаптера изменения logcfg в версии 0.4.1 нет. Используй доступные средства текущего harness; не вызывай вымышленные подкоманды `techexpert logcfg`. Готовый текстовый ТЖ можно прочитать по узкому профилю из [контракта CLI](../techexpert/references/local-cli.md); наличие такого парсера не означает включённого сбора.

## Подготовить конкретный план

1. Установи недостающие данные: какой эпизод и период требуется наблюдать, на каких узлах и для какой операции. Сохрани уже известные сведения; не спрашивай заново заполненные поля профиля.
2. Прочитай явно указанный существующий `logcfg.xml`, если он доступен. Различай отсутствие файла, отсутствие прав и неизвестное расположение. Для неизвестного расположения запроси у ответственного администратора конкретный путь и узел; не объявляй универсальный путь найденным.
3. Проверь фактическую версию платформы и назначение существующих правил. До предложения конкретных элементов XML и параметров проверь их по документации именно поддерживаемой версии. Корректный XML ещё не доказывает, что настройку понимает платформа.
4. Подготовь минимальный проект изменений с сохранением посторонних правил: узлы, нужные события и фильтры, временное окно, ограничения объёма, каталог вывода, способ проверки поступления данных и условие остановки. Если исходного файла нет, возвращай список необходимых сведений и план, а не фиктивный diff.
5. При наличии достаточных сведений подготовь diff, применение, проверку результата и возврат с сохранением исходной версии. Для уже разрешённого изолированного опыта продолжай этот план средствами harness без повторных вопросов. Если применение не входит в поручение, передай конкретную инструкцию ответственному администратору. Возврат не должен затирать последующие изменения другого администратора.

Для нового сбора, который затем будет читаться локальным профилем `1c-tj-text-v1`, проверь текстовый формат и размещение `folders` либо `plain`. После получения файла прочитай настоящий заголовок и задай отдельный `timestamp_format`: `minute` требует часового файла, `rotation_hours: 1` и `file_hour` со смещением; `iso` требует `utc_offset`. Правило одинаково для обоих размещений: на локальной 8.3.27.1989 `plain` с часовым периодом по умолчанию дал короткое время. Попроси сохранить версию платформы, временное смещение узла и контекст файлов вместе со снимком. Наличие 1С на этом ПК не определяет версию другого источника. Не объявляй журнал совместимым по одному имени файла или примеру документации.

Сверяй параметры с [руководством 8.3.27, §3.24](https://1c-dn.com/library/tutorials/1c_enterprise_administrator_guide_file_mode_8_3_27/). Длительность в текстовой записи измеряется в микросекундах; исторический фильтр `duration` использует другую единицу. Для целевого фильтра `Durationus` см. [официальную методику мониторинга](https://its.1c.ru/db/content/metod8dev/src/developers/scalability/methods/i8105809.htm). Не переноси числа между этими полями без проверки единиц.

## Граница результата

Для инструментированного SC-01 профили `1c-file-job-markers-v1` и `sc01-order-load-v1` используют точные SDBL-маркеры и сведения SESN для привязки участка ТЖ к UUID задания. Не обещай, что настройка ТЖ покажет исходящие HTTP-запросы: такое событие в данном профиле не подтверждено. Проверка HTTP использует отдельные клиентские и серверные свидетельства по UUID, nonce и request ID. Совпадение времени или долгий CALL не заменяет эту связь; сумма интервалов запросов не является длительностью задания.

Сообщи, что прочитано, подготовлено или фактически применено и чем проверен результат. `init` не применяет logcfg, не включает постоянный сбор и не перезапускает службы. Наличие этого навыка само по себе не разрешает изменения рабочей системы. Подготовленный план не является доказательством того, что события уже собираются. Прежде чем анализировать материалы, проверь фактическое покрытие и профиль формата. Новая настройка не восстанавливает события прошлого эпизода, а успешный разбор не подтверждает полноту собранных данных.

Если текущий запрос требует только анализа готового манифеста, вернись к [investigate](../investigate/SKILL.md), не делая настройку ТЖ обязательной предпосылкой.
