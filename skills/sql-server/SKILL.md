# Microsoft SQL Server

Прочитайте профиль среды и `python techexpert.py doctor`: клиент sqlcmd, версия и права проверяются отдельно. Файловая ИБ не имеет SQL-базы.

Текущий комплект не содержит проверенного исполняемого адаптера SQL Server. Не переносите команды postgresql на SQL Server и не называйте отсутствие адаптера отсутствием нагрузки. При наличии разрешённых средств harness подготовьте минимальный план чтения текущих запросов/ожиданий/блокировок и отдельно проверьте Query Store, Extended Events либо сохранённые снимки. Условия доступа и применимость DMV сверяйте с официальной документацией именно фактической версии Microsoft.

Текущий DMV не восстанавливает прошлый инцидент. Сброс накопительной статистики, получение фактического плана с исполнением, включение трассировки, изменение индексов и отмена запросов — отдельные изменяющие действия; они не следуют из настройки адреса источника. Сопоставляйте SQL с ИБ и запросом 1С по свидетельствам.

Команды запускайте из проверенного корня пакета; [общий контракт](../techexpert/references/local-cli.md) задаёт состояние и формат ошибок.
