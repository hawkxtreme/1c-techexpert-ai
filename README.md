# 1C TechExpert AI

Проект автономного ИИ-эксперта по техническим инцидентам 1С:Предприятия. Он задуман для расследования сбоев и проблем производительности по журналам, данным СУБД и экспертным кейсам.

Сейчас в репозитории подготовлены структура проекта, методика расследования и черновик Skill. Первый этап разработки — локальный CLI для анализа технологического журнала (ТЖ) и формирования отчёта с доказательствами.

## Первый сценарий

«Фоновое задание загрузки заказов выполняется 45 минут вместо обычных пяти».

По симптому, периоду и доступным журналам эксперт должен найти конкретный запуск, отделить ожидание в очереди от выполнения и сопоставить вызовы с событиями SQL, блокировок и ошибок. В отчёте нужны ссылки на исходные события, подтверждённые факты, гипотезы и перечень недостающих данных. Подробнее в [методике расследования](knowledge/playbooks/slow-background-job.md).

## Что планируется

- Работа с локальными архивами на Windows и Linux.
- Подключение журнала регистрации (ЖР), кластера 1С, MS SQL Server и PostgreSQL в режиме чтения.
- CLI и локальный GUI поверх общего диагностического ядра.
- Подключение агентных инструментов через Skill и пополнение экспертной базы через pull requests.

## Участие

Ошибки, предложения и экспертные кейсы можно оформить через [формы Issues](https://github.com/hawkxtreme/1c-techexpert-ai/issues/new/choose). Для вопросов и обсуждения методик есть [Discussions](https://github.com/hawkxtreme/1c-techexpert-ai/discussions).

Новый кейс оформляй со статусом `draft`. Укажи версии платформы и СУБД, условия применимости и доказательства. Статус `verified` ставится после экспертной проверки. Публикуй только обезличенные данные. Рабочие журналы и отчёты храни локально в игнорируемой папке `.local/`.

Лицензия пока не выбрана.
