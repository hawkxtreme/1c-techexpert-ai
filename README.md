# 1C TechExpert AI

Помощник расследования технических проблем 1С. Он использует ИИ текущего чата, а локальные инструменты проверяют источники, считают показатели и сохраняют материалы расследования.

## Первый запуск

Нужен Python 3.11 или новее. Из корня репозитория откройте проектный навык `$techexpert` в агентном клиенте и опишите проблему. Чтобы настроить источники, попросите агента запустить `init`. Мастер предложит выбрать базы, добавить источники и сохранить профиль. Затем продолжите в том же чате. Если клиент ещё не обнаружил навык, попросите агента прочитать его [точку входа](skills/techexpert/SKILL.md).

Для установки плагина Codex из распакованной поставки выполните:

```text
python techexpert.py doctor --check-plugin
codex plugin marketplace add .
codex plugin add 1c-techexpert-ai@1c-techexpert-local
```

В установленном плагине выберите навык `1c-techexpert-ai:techexpert`. Для отдельной проверки комплекта доступны команды:

```text
python techexpert.py readiness
python techexpert.py demo
```

Демо использует три синтетические отметки. Ожидается 4 минуты в очереди, 41 минута выполнения и 45 минут всего. Проверку на реальном ТЖ выполняют отдельно, с указанным интервалом и источниками. [Установка и первый запуск](skills/techexpert/references/first-run.md)

## Проверенные возможности

| Задача | Проверенный профиль и руководство |
| --- | --- |
| Выбрать базы и настроить источники | Мастер принимает ручной ввод, список стартера и доступные свойства RAS. Источники задаются по отдельным адресам. [Настройка](skills/setup-and-access/SKILL.md) |
| Разобрать ТЖ и ЖР | Текстовый ТЖ 8.3.27.1989, последовательный LGF/LGP и отдельный профиль чтения LGD. [ТЖ](skills/tech-log/SKILL.md) · [ЖР](skills/event-log/SKILL.md) |
| Сверить серверные данные | Отдельные операции чтения RAC, SQL Server 2022 и PostgreSQL. Сквозную работу на лицензированном Dev-кластере предстоит проверить. [RAC](skills/rac/SKILL.md) · [SQL Server](skills/sql-server/SKILL.md) · [PostgreSQL](skills/postgresql/SKILL.md) |
| Измерить или проверить исправление | Метрики Windows/Linux, APDEX и сравнение сохранённых эпизодов. Пресет сбора — 5 минут с шагом 1 секунда, оба значения можно изменить. [Метрики ОС](skills/os-metrics/SKILL.md) · [Проверка исправления](skills/verify-improvement/SKILL.md) |
| Проверить исходники и клиентскую задержку | Исходники из каталога или Git. Клиентские измерения в проверенном профиле TestClient/Testpilot. [Исходники](skills/onec-source/SKILL.md) · [Клиентская диагностика](skills/client-ui-performance/SKILL.md) |

Для файловой базы мастер предлагает применимые источники. Подключения к СУБД и RAC появляются у серверных баз. Настроенный адрес, результат проверки доступа и пригодность записей для конкретного инцидента проверяются отдельно.

Профиль и доказательства сохраняются в частном хранилище на компьютере, где работают инструменты. Адрес каждого источника задаётся отдельно. В Git входят проверенные примеры, навыки и авторские карточки знаний. Правила доступа и обезличивания описаны в [инструкции по работе с материалами](skills/report-and-evidence/SKILL.md).

## Разработка

`AGENTS.md` описывает правила работы с кодом и данными. В Git checkout файл `docs/requirements.md` фиксирует согласованные требования, а `docs/dev-windows.md` содержит порядок переноса на Windows Dev и готовый тестовый промпт.

```text
python -m unittest discover -s tests -v
python scripts/generate_bundle_manifest.py
python scripts/package_plugin.py ../1c-techexpert-ai-local.zip
```

Команда упаковки выполняется из checkout и ждёт новый путь для ZIP. Схемы и границы операций возвращает `python techexpert.py capabilities`.
