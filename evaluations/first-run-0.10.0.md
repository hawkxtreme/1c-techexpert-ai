# Готовность первого запуска SC-01, локальный профиль0.10.0

Реализована локальная часть REQ-133/115: единый отчёт readiness в CLI, init и GUI. Проверяются совместимая версия и UTF-8/LF инвентарь инструкций/18skills, runtime, шаблонов, справки, знаний и синтетического примера. Проверяется фактический локальный поиск по17связанным карточкам. Инвентарь ограничен256членами,1МиБ на файл и8МиБ прочитанных членов; дополнительные семантические валидаторы имеют свои фиксированные пределы. Хэши не удостоверяют издателя. Код и каталог, из которого он выполняется, остаются доверенной границей установки; это не sandbox произвольного checkout.

Агент передаёт хэш действительно прочитанной точки входа. Это caller_reported_loaded, не независимая аттестация модели. Без подтверждения инструмент сообщает needs_harness_confirmation. Отсутствие профиля, повреждённый профиль, неприменимость SQL/RAC к файловой ИБ и ещё не проверенные подключения разделены. Readiness не открывает адреса из профиля, не проверяет возможность записи, не устанавливает компоненты, не подключает источники и не запускает сбор/1С. Python при отсутствии готовит человек штатным способом; установка не автоматизирована.

На этом Windows/Python3.14 проверен сохранённый контролируемый SC-01 с закреплённым профилем1: анализ готовых файлов доступен, SQL/RAC неприменимы, хэши профиля и head расследования неизменны. В Chrome DevTools на отдельном пустом состоянии проверены ready-отчёт, кнопка «Проверить на примере» без настройки ИБ и явный POST demo. Получены240с очереди/2460с выполнения/2700с всего, origin synthetic, без профиля и нового Investigation. После возврата readiness читает тот же case_id и проверяет отчёт, манифест и исходный снимок. Ошибок консоли/горизонтального переполнения не обнаружено; собственная вкладка закрыта, HTTP-helper ограничен TTL120с.

Тесты повреждают одноразовые копии комплекта: карточки/связи/инструкции/каталоги, версии/формы JSON, необъявленные или внешние пути, сохранённый отчёт и исходник demo. Проверены CRLF, отсутствие optional PATH tools, pinned контекст, HTTP авторизация/Origin/закрытый запрос demo и повтор без перезапуска. Windows junction проверяется штатным PowerShell5.1; символьная ссылка явно пропускается, если токену не хватает SeCreateSymbolicLinkPrivilege. Native-1C, SQL и новая слепая диагностика этими тестами не подтверждаются.

Остаются отдельными приёмками другие ОС/версии Python, реальные пользовательские роли, установка/обнаружение плагина и дальнейшие миграции/обновление. Синтетические три отметки не устанавливают причину и не заменяют лабораторные пять пар или производственный инцидент45минут. Полное ТЗ не объявляется выполненным. Пакет остаётся локальным, без внешней публикации.
