# Локальная проверка состояния расследований 0.7.0

16 ноября 2026 года. Это проверка хранения, связей и маршрутов; новая слепая проверка качества модели и реальные сутки наблюдения здесь не проводились. Предыдущая независимая слепая проверка относится к [SC-01](sc01-codex-skill.md).

| Область | Проверено |
| --- | --- |
| История | Новая ревизия сохраняет прежние JSON/Markdown, родительский хэш и receipt. Устаревший writer отклоняется. Незавершённая ревизия/lock не перезаписывают историю. |
| Доказательства | Case, artifact и comparison проходят проверку исходных снимков. Битый снимок и dangling E-ID отклоняются. Числа извлекаются JSON pointer из отчёта инструмента; текстовое утверждение harness не получает независимого подтверждения смысла. |
| Причина | Execution и три cause_state независимы. Поддержанная гипотеза, основания и альтернативы обязательны для структурно допустимого confirmed. Изменение основания снимает старое объяснение/эффект с текущей ревизии. |
| SC-01 | В новую модель подключены прежние реальные пять пар, runtime/HTTP/capture и сравнение. Из инструментов извлечены медианы 13/3 с, обращения 200/10 и matches_expected. Сохранена интерпретация текущего harness с ограничением лабораторного профиля. Это повторное использование измерений, не новый опыт в 1С. |
| Шаблоны | TPL-01–TPL-10, отдельные время/масштаб. Вариант проведения документа сохраняет клиентскую ветку и исключает SQL/RAC для file/unknown; неподдержанные проверки показываются до запуска. |
| GUI/CDP | Описание пришло из чата; выбран вариант проведения, reproduce/several; профиль и ревизия расследования сохранены, исходная task осталась в истории. Сбор при сохранении не запускался. |
| Помощь | Комплектные назначения, ожидаемые форматы, примеры, доступы и подготовка Windows/Linux для шести источников; одна модель справки для GUI и CLI. |
| Редкое повторение | Программный случай: план на 86400 с → awaiting_occurrence → сохранение/возврат → внешнее сообщение → analyze_episode с тем же ID. Сообщение остаётся reported_not_verified без свидетельств. Модель не запускается для постоянного опроса. |

В версии хранятся описания планов и учёт, сообщённый harness; общего исполнителя и глобального контроля его токенов нет. Суточное число в плане не расширяет одноразовый ОС-коллектор до суток. Для реального длительного сбора выбираются проверенные средства источников/внешнего исполнителя и отдельно проверяется покрытие. Пользовательские варианты шаблонов, автоматическое восстановление прерванной записи, внешняя публикация, приёмка реальными пользовательскими ролями и серверный лицензируемый SC-01 остаются открытыми проверками.
