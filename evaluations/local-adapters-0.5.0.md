# Локальная проверка дополнительных источников 0.5.0

Дата: 16 ноября 2026. Это проверка конкретного окружения и возможностей инструментов; она не заменяет приёмку всего ТЗ, человеческое тестирование удобства и сравнение CodeMode/MCP.

| Путь | Проверка и граница |
| --- | --- |
| APDEX | Границы T/4T, ошибки, неполные данные, смешанные операции и дубли; CLI сохраняет исходный снимок и возобновляет artifact. Только нормализованные измерения, без заявления совместимости любой БСП. |
| Windows ОС | Windows 11 26200, Python 3.14, PDH с языково независимыми именами. Реальная короткая серия 3 с / 1 с: 4 отсчёта, 30 рядов метрик, без ошибок регистрации счётчиков. Первая скорость неизвестна. |
| Linux ОС | Linux 6.6.87.2 WSL2, Python 3.12.3 в Docker: 4 отсчёта за короткую серию. CPU/блочные счётчики относятся к Linux VM, сеть — namespace контейнера. |
| SSH | Windows OpenSSH → отдельный Linux-контейнер → непривилегированный пользователь. Проверен ключ сервера из принадлежащего тесту контейнера; 4 отсчёта и 46 рядов. Контейнер остановлен после проверки. |
| WinRM | Подготовлены валидация и лаунчер Windows PowerShell 5.1 с существующей авторизацией Negotiate. Реальное выполнение не подтверждено: служба на ПК остановлена, настройки не менялись. |
| RAS/RAC | Linux 1С 8.3.27.1989, отдельный сервер и RAS. Прочитаны кластер, ИБ, серверы, процессы, соединения и сеансы. Создана пустая sc01_server. Текущие списки не интерпретируются как история. |
| PostgreSQL | Подписанные пакеты PostgreSQL для 1С 16.15, Debian 12. Все пять операций каталога выполнены под отдельной ролью с pg_monitor, без superuser, READ ONLY. Отсутствие pg_stat_statements проверено отдельно и вернуло unavailable. Расширение для последующей проверки включено только в принадлежащей тесту БД. |
| Исходники | Реальный XML/BSL-каталог SC-01: 7 файлов; поиск нашёл HTTPСоединение. Снимок Git HEAD этого репозитория: фиксированный commit, 14 XML/BSL-файлов. Тест с clean-фильтром доказал отсутствие запуска кода Git-фильтра. Частичные/promisor-репозитории отклоняются до чтения объектов. |
| GUI | Chrome/CDP: файловая база, отсутствие SQL/RAC среди её источников, пресет 300/1, изменение на 120/2, отдельная локальная проверка, сохранение и повторное открытие. Проверено отсутствие запуска сбора при сохранении. Это автоматизированный проход, не приёмка двумя реальными ролями. |
| Знания и навыки | 17 связанных карточек; 18 skills, включая входной techexpert и 17 профильных. Индекс проверен офлайн, все SKILL.md прошли штатный валидатор в UTF-8. Наличие guidance skill не объявляет соответствующий адаптер реализованным. |

Linux-сервер и клиент собраны из предоставленного официального установщика 8.3.27.1989. При подключении из Windows воспроизведено ограничение определения принадлежности процессов при Docker NAT. Linux-клиент достиг сервера, но проверка лицензии завершилась отказом привязки. Пользователь исключил дальнейшие лицензионные шаги на этом ПК. Полная загрузка конфигурации и серверный SC-01 не пройдены. Рабочие системы, настройки сети и исходный файл лицензии не изменялись; серверный контейнер остановлен.

Приватные исходные наблюдения, полные SQL-тексты, журналы и квитанции находятся в локальном состоянии теста и не входят в Git/пакет. Публичные карточки содержат собственную методику и URL; исходные книги, статьи и иллюстрации ИТС не включены.

Автотесты и portable-package проверяют контракты и воспроизводимость инструментов. Они не доказывают, что ИИ поставил правильный диагноз в новых сценариях; предыдущая слепая проверка относится к [SC-01](sc01-codex-skill.md).
